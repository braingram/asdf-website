# ASDF for Julia

The {{ extref("asdf:asdf", "asdf") }} Julia implementation is available on [github](https://github.com/JuliaAstro/ASDF.jl) and the [General registry](https://github.com/JuliaRegistries/General). Julia users can install the package from the Julia REPL:

```julia-repl
$ pkg> add ASDF
```
